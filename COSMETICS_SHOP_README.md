# CHIMPS RUNNERS Cosmetics Shop

The shop loader expects this model at:

`assets/CHIMPS_RUNNERS_Cosmetics_Shop.glb`

The model supplied in chat was trimmed to keep the shop, six cosmetic stands, shelving, carpet, and mirror while removing surrounding city/restaurant pieces.

The six stands currently open category panels:
- Headwear
- Shirts
- Badges
- Back accessories
- Wrist accessories
- Seasonal cosmetics

These are stand interactions/placeholders, not yet a working purchase/equip system. Actual cosmetic models and the player rig are needed for previews and body attachment.
